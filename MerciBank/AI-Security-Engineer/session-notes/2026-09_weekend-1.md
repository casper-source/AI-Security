## Day 1 — Foundations recap & hands-on red-team (~3h17m)
Framed as an advanced follow-on: today is a recap of foundations, tomorrow is theory, Week 2+ is
hands-on agentic. Flow:
1. Intros & framing; program outline; required stack (promptfoo, Node, Python, Git, an AI coding assistant).
2. Concept recap through a security lens — tokens, context window, system prompt, temperature, model fingerprinting (details in the Day 1 guide).
3. Recap of promptfoo essentials: config/providers/prompts, deterministic vs non-deterministic assertions, LLM-as-judge, red-team plugins & strategies, OWASP LLM Top-10.
4. Exercise 1 — "break your own chatbot" (most pairs did not finish in the slot; setup rust + ambiguous wording, clarified live).
5. Exercise 2 — higher-stakes audit of a system with sensitive-data access; rank findings by severity.
6. Close — homework: finish the exercises, read Dario Amodei's post.

Tools shown: Tokenizer Flow, context-window simulator, temperature simulator, P4RS3LT0NGV3,
promptfoo red-team (UI + CLI), Claude Code / Codex. A promptfoo caching note surfaced live: a
regenerated red-team file kept an old system prompt; `--no-cache` was the fix.

## Day 2 — The playbook (~3h45m, lecture/roundtable)
A ~55-slide deck in four parts: AI history, anatomy of the agentic world, why agentic testing is
new/hard, and the role + jobs. Flow:
1. Recap / aha-moments from Day 1's red-team exercise.
2. 90-year AI history → transformers → GPT lineage → prompt injection (2022) → function calling → AutoGPT → multi-agent → swarms → recursive self-improvement.
3. Anatomy of an agent: LLM + memory + loop + tools + goal + "a computer"; tools/function calling, MCP, Skills, RAG, memory (+ poisoning), A2A, orchestrators, computer use, guardrails, sandbox.
4. Skill / tool-description poisoning + defenses.
5. "Why static testing breaks on agents" — from AI testing to AI system assurance; the definition of attack surface. Attack-surface breakout exercise.
6. The role & market: reading job posts; AIVSS previewed and deferred to Weekend 2.
7. Job-hunt exercise; Claude Code demo (repo → promptfoo YAML); homework + feedback.
